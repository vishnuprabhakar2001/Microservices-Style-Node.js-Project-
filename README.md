# Microservices-Style-Node.js-Project-
Node.js Microservices Backend Project

This is a Node.js backend project implemented in a microservices architecture. The project demonstrates a scalable backend design where different services use separate MongoDB databases to handle their respective data independently, while still serving the same application.

Key Features

Microservices Architecture – Each service is modular and runs independently.

Multiple Databases – Two different MongoDB databases are used for different services, ensuring data separation and better scalability.

RESTful APIs – Each service exposes its own set of APIs for CRUD operations.

Express.js Framework – Built using Express.js for lightweight and efficient routing.

Environment Configuration – .env files used for secure configuration management.

Modular and Scalable – Easily extendable to add more services or databases.
